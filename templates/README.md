# FHEVM SDK Templates

This directory contains template projects demonstrating FHEVM SDK integration across different frameworks.

## Available Templates

### Next.js Template

Located in `../examples/nextjs-demo/`

A complete Next.js 14 application with:
- Full FHEVM SDK integration
- App Router architecture
- API routes for server-side operations
- Reusable components and hooks
- TypeScript support
- Tailwind CSS styling

**Quick Start:**
```bash
cd ../examples/nextjs-demo
npm install
npm run dev
```

## Template Structure

Each template includes:
- Complete project setup
- FHEVM SDK integration examples
- Encryption and decryption workflows
- Type definitions
- Documentation
- Ready-to-deploy configuration

## Using Templates

1. Copy the template to your project directory
2. Install dependencies
3. Configure environment variables
4. Start development server

For detailed integration guides, see the main [README.md](../README.md) and [SDK_DOCUMENTATION.md](../SDK_DOCUMENTATION.md).
